# Changelog

## 0.1.0

- Package the local photo workflow as `dollyzoom` with a `photo-dolly` alias.
- Render anchored MP4/GIF dolly zooms from a cached Gaussian reconstruction.
- Offer suitability assessment, a visual anchor picker, presets, smooth/bouncy
  motion, crop control, BPM timing, and an interactive local viewer.
- Add versioned JSON results and a schema command for shell-capable agents.
- Keep runtime state outside the package and refuse nonempty output directories.
- Add source/package allowlists, private-artifact ignores, CI, specifications,
  contribution guidance and explicit third-party/model licensing notes.
